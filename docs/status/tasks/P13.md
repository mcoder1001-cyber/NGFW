## Acceptance

- **Every CLI command maps to a documented REST call** — `Command.Ops` lists operationIds; `TestEveryCommandMapsToDocumentedREST`
  checks each against the generated table (commands without REST — `configure`, `edit`, `up`, `top`, `help`, `show bgp summary`,
  `show ipsec sa` — must state why; the reference prints it). `grep -rn vppctl apps/cli`:
  ```
  $ grep -rn vppctl apps/cli; echo "grep exit=$?"
  grep exit=1
  ```
  plus `make -C apps/cli check`: `ok: apps/cli talks only to the REST API` (also no `/run/vpp`, govpp, agent socket).
- **Completion offers valid config paths and enum values from the live schema** — e2e transcript below (`rxMode ?` →
  `polling interrupt adaptive`; `mt?` → `mtu … [integer 68..9216]`), unit `TestCompletionFromTheLiveSchema`.
