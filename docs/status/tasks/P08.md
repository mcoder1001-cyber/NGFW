# P08 — Vertical slice: interfaces end to end

Branch `task/P08` (worktree `/root/ngfw-wt/P08`), slot 1 (`w1`, API 3100, web 5100, metrics 9111, DB `vrx_w1`, rig
10.1.{1,2}.0/24), data path **af_packet** (D-010). Two workers: the first (05:00–05:45) built the agent wiring, the
contract and the API; the second (CONTINUE, 07:20–) merged DF-5, wired its stores, wrote and ran the topology and
restart-safety tests, built the UI, docs and evidence. Summary for later features: `docs/status/vertical-slice.md`.

## What was built

**Agent** (`apps/agent/internal/{subsystems,desired,agent}`, `cmd/vrx-agent`)
- `subsystems.Register`: one registry for the product agent — core (loopback, interface-ip table/address, VRF, route),
  DF-1 (sub-interface, alias `interface/<name>` observe-only, admin-state, MTU, MAC, promisc, rx-mode, rx-placement),
  af_packet host-interface, DF-8 DHCP client; domain map `interfaces | vrfs | routing` (`Health.subsystems`).
  MTU and rx-mode are wrapped so a value equal to the creation default is a verified no-op instead of DF-1's error.
- Persisted stores in `VRX_AGENT_STATE_DIR`, keyed with the VPP boot identity (D-080): DF-1 claim store
  (`iface.SetClaimStore`, `claims-iface-<owner>.json`), D-076 boot/applied-once records (`df7.SetBootStore`,
  `boot-<owner>.json`), keyed claims per family (`KeyedClaims("acl"|"nat")`), DF-2 classify store, **DF-5**
  `IPsecOptions()/IKEv2Options()` = `WithBootStore(<file store>)` + D-096 keyer (`vpn-<owner>.key`, 0600) + globals flag.
  No in-memory default is installed by the product agent.
- `Connected()` hook on every VPP (re)connect: boot identity → expired claims pruned, index cache invalidated,
  **DF-8 `Reconnected()`**.
- `desired.Interfaces` builder: logical names, `interface/<name>` alias per interface, every reference through the alias
  (D-065/D-069/D-073a); creators `host-<netdev>` → af_packet, `loop<N>` → loopback, `<parent>.<id>` → exact-match
  sub-interface; attributes, addresses, VRF, DHCP; `unnumbered` reported as `agent.unsupported-field`.
  `desired.Assemble` rebuilds the document from Retrieve; descriptions from the stored desired state (D-073b).
- `InterfaceState` RPC (additive contract 51b7c42): live table (sw_if_index, type, admin/link, MTU/link MTU, MAC,
  addresses, VRF + table, parent/VLAN, managed, rx-mode, description).

**API** (`apps/api/src/state`): `GET /api/v1/state/interfaces` = live state (InterfaceState) + Retrieve (`actual`) +
running (`config`) + counters + `hasPendingChange` (candidate ≠ running); `GET /api/v1/state/interfaces/{name}/counters`.
Config editing uses only the generic P06 pointer routes. Client regenerated (contract c02aa32).

**UI** (`apps/web/src/domains/interfaces`): `ServerDataGrid` (name, type, admin, link, MTU, addresses, VRF, RX/TX bps+pps,
sparkline, errors, pending mark), drawer with live state, `SchemaForm` of the generated interface schema (localized titles,
help and groups), sub-interface table with add/edit/remove, add-interface dialog, en + fa (RTL). Nav entry available.

**Tests**: `test/topology/interfaces` (own Go module; `run.sh`): `TestInterfacesVerticalSlice` (topology, restart-safety,
cleanup) and the opt-in `TestInterfacesScreenshots`; unit tests in agent/subsystems/web; API e2e on the slot DB.

**Docs**: `docs/user/interfaces/basics.md` (screenshots, REST, CLI), `docs/status/vertical-slice.md`.
