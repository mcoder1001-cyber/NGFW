# Descriptors — l2 plugin (DF-1)

Package `apps/agent/internal/descriptors/l2`, models `l2_model.proto` (agent-internal stand-in, D-055).
`l2.Register(r, client, owner)`. Interface fields hold full interface keys ([interface.md](interface.md)).

| Object type (descriptor) | Key | Depends on | VPP messages | Update | Notes / limitations |
|---|---|---|---|---|---|
| `l2.bridge-domain` | `l2.bridge-domain/<bd id>` | — | `bridge_domain_add_del_v2` (with `bd_tag`), `bridge_flags`, `bridge_domain_set_mac_age`; Retrieve `bridge_domain_dump` | flags and mac-age in place; id change = ErrRecreate | flood, uu-flood, forward, learn, arp-term, arp-ufwd, mac-age (minutes, 0 = off). Ownership = `bd_tag "<owner>:<id>"`. Ids: tests use the slot's table range (`N000–N999`), production the API allocator. `mac-age` is part of this object (no separate object). |
| `l2.bridge-domain-member` | `l2.bridge-domain-member/<bd id>/<interface id>` | bridge-domain key, interface key | `sw_interface_set_l2_bridge` (enable, `port_type` normal / bvi / uu-fwd, `shg`); remove = `enable=false` (returns the interface to L3 — VPP's "remove from bridge"; there is no separate message); Retrieve `bridge_domain_dump.sw_if_details` + `bvi_sw_if_index` / `uu_fwd_sw_if_index` | ErrRecreate | One BVI per bridge domain (VPP rejects a second). |
| `l2.xconnect` | `l2.xconnect/<rx interface id>` | rx and tx interface keys | `sw_interface_set_l2_xconnect`; Retrieve `l2_xconnect_dump` | tx change in place; rx change = ErrRecreate | Decision: **one object per direction** (rx → tx), a bidirectional cross-connect is two objects. Mirrors VPP (each rx has exactly one xconnect target) and keeps Retrieve a plain decoding. Delete returns rx to L3. |
| `l2.fib-entry` | `l2.fib-entry/<bd id>/<mac>` | bridge-domain key (+ interface key unless filter) | `l2fib_add_del` (static / filter / bvi); Retrieve `l2_fib_table_dump` | ErrRecreate | Learned entries are runtime state, never retrieved. VPP stores filter entries with the static bit: the model keeps `static=false` for filter entries. The static **BVI entry VPP installs by itself** for the BVI's own MAC when an interface joins as BVI belongs to the member object and is not retrieved (host-verified; otherwise every BVI would produce a Delete in every plan) — do not configure it. MACs lower-case. |
| `l2.flags` | `l2.flags/<interface id>` | interface key | `l2_interface_feat_flags_set` / `l2_interface_feat_flags_get` | in place | Per-interface learn / forward / flood / uu-flood / arp-term / arp-ufwd **mask** of a bridge member (VPP ANDs it with the bridge domain's flags). Present ⇔ the mask differs from the member default VPP sets on join: everything on, **learning off for the BVI** (l2_input.c; host-verified). Desiring the default → `ErrEqualsBridgeDefault`. Delete restores the default. The prompt's `l2_flags` message is the older bitmap form; `l2_interface_feat_flags_*` is the 26.06 get/set pair and the only one with a getter. |
| `l2.vlan-tag-rewrite` | `l2.vlan-tag-rewrite/<interface id>` | interface key (usually a sub-interface) | `l2_interface_vlan_tag_rewrite`; Retrieve `sw_interface_dump.vtr_op / vtr_push_dot1q / vtr_tag1 / vtr_tag2` | in place | push-1/2, pop-1/2, translate 1-1/1-2/2-1/2-2 (QinQ stacking). `disabled` is the absence of the object and what Delete sets. |
