## What was built

### `apps/agent/internal/scheduler/` — the reconciler contract (AD-3)

- `descriptor.go`: `Key` (+ `Join`, `Descriptor()`, `ID()`), `KV{Key, Value proto.Message, Meta any}`, `Dependency{Key, Optional}`,
  `ErrRecreate`, the `Descriptor` interface exactly as specified (`Name/KeyOf/Dependencies/Create/Update/Delete/Retrieve`),
  `Registry` interface, `Plan{Create, Update, Delete []KV}` (+ `Empty`, `Len`), `Result{Key, Op, Err}`, `Op*` constants.
  The package doc spells out the transaction semantics P05 implements and descriptors rely on: key convention, validation
  of mandatory dependencies, topological order with deterministic tie-break, `proto.Equal` diff, create/update forward and
  delete in reverse, `ErrRecreate` cascading to dependents, verify by re-Retrieve, reverse-order rollback → `ROLLED_BACK`,
  Meta lifecycle, Retrieve rules, ownership on the shared VPP.
- `registry.go`: `MapRegistry` (`NewRegistry`, `Add` → `ErrNilDescriptor`/`ErrInvalidDescriptorName`/`ErrDuplicateDescriptor`,
  `Register` = panicking form required by the interface, `Get`, `ForKey`, `Descriptors`/`Names` in registration order, `Len`),
  `ValidName` (`<plugin>.<object>`, lower-case/digits/`-`/`.`, never `/`).
- `registry_test.go` (order, lookup, duplicate/invalid, panic, key helpers) and `example_descriptor_test.go`: **the example
  descriptor unit test using the fake** — a loopback descriptor (create with owner tag → Retrieve equals desired incl. Meta,
  other owners and `local0` filtered → MTU update in place → rename returns `ErrRecreate` → delete → Retrieve empty →
  `vpp.ErrDisconnected` and non-zero `Retval` surface as errors). Message types are stand-ins because `apps/agent/binapi`
  (P04) is not merged; the file says so and shows where the generated client goes.

### `apps/agent/internal/vpp/` — the VPP client contract and its fake

- `client.go`: `Client` = govpp `api.Connection` (`Invoke`, `NewStream`, `WatchEvent`) + `Connected()`, with
  `var _ api.Connection = (Client)(nil)` so the generated `*_rpc.ba.go` service clients accept it directly; `ErrDisconnected`.
  Doc explains use from DF-* (generated `NewServiceClient`, dump = `Recv()` until `io.EOF`, `api.RetvalToVPPApiError`) and
  implementation by P05 (`*core.Connection`).
- `tag.go`: `OwnerTag(owner, id)` → `"w2:loop200"` (≤ 63 bytes) and `ParseOwnerTag` — the ownership stamp for P05 §3b and
  every DF-* Retrieve filter.
- `fake/`: in-memory `vpp.Client` recording every request; handlers by VPP message name (`On`/`Reply`/`Fail`), `Invoke` copies
  the canned reply into the caller's struct (type-checked), `NewStream` replays the dump pattern (details then the
  `control_ping` reply supplied via `WithControlPingReply`), `WatchEvent`/`Emit` for events, `SetConnected`, `Calls`/`CallsNamed`.
  Unknown requests fail with `ErrNoHandler` instead of silently succeeding.
- `vpptest/`: shared-host test helpers — `SkipUnlessIntegration`, `Prefix`, `Slot`, `Name` (IFNAMSIZ-checked),
  `LoopbackInstance` (`<slot>00..99`), `TableBase`, `NATPool`, `LockLab` (`flock -s /run/lock/vrx-lab.lock`, released in Cleanup).

### `apps/agent/internal/renderers/` — the daemon renderer contract and helpers

- `renderer.go`: `Renderer{Name, Render, Validate, Apply, Retrieve}` as specified; `Files map[string]File`,
  `File{Mode, Owner, Content, Secret}`; `Files.Validate` (absolute clean paths, explicit permission-only mode, secret files not
  world-readable), `Paths`, `Redacted`. Package doc: Render pure → Validate on a staged copy → Apply = snapshot/write/reload/
  restore → Retrieve structured.
- `helpers_files.go`: `WriteFileAtomic` (temp in same dir, fsync, chmod, chown by name, rename, fsync dir), `WriteFiles`,
  `TakeSnapshot`/`Restore` (content+mode+owner or absence; idempotent), `Stage` (temp tree for validators).
- `helpers_exec.go`: `Allowlist`/`NewAllowlist`, `Command{Path, Args, Stdin, Dir, Timeout}`, `Output`, `ExitError`, `Runner`
  interface, `SystemRunner` (fixed argv from an allow-listed absolute path, no shell, fixed minimal env, default 30 s
  timeout with kill, bounded output capture), `RecordingRunner` for unit tests.
- `helpers_template.go`: `Ident`, `Line`, `Quoted`, `JSONString`, `Addr`, `Prefix`, `Network`, `Funcs`, `NewTemplate`
  (`missingkey=error`), `Execute`/`ExecuteTemplate` + `CheckRendered` backstop (no CR/NUL/ESC/U+2028, valid UTF-8).
- Tests for all of the above incl. the hostile-string table (`"; rm -rf /`, LF/CRLF injection, NUL, ESC, U+2028, bad UTF-8),
  a real `/bin/echo` run proving shell metacharacters stay literal, env non-inheritance, timeout kill, output cap, and
  `TestAllowlistDocumented`, which scans every non-test `.go` file under `internal/renderers/` and fails on a binary path not in
  `ALLOWLIST.md`, on `exec.Command` outside `helpers_exec.go`, or on `sh -c`/`bash -c`.
- `README.md` (where files go, the four methods with code, helper table, runner rules, unit + integration test rules for the
  shared host) and `ALLOWLIST.md` (rules, empty *Active* table, *Planned* rows for the daemons the templates name).

## Decisions taken (for `docs/decisions/LOG.md`)

| decision | options considered | why | reversal cost |
|---|---|---|---|
| `vpp.Client` is a superset of govpp `api.Connection` (`Invoke`, `NewStream`, `WatchEvent`, `Connected`) | (a) bespoke `Invoke/Stream/Connected` + adapter (b) embed `api.Connection` methods | generated `*_rpc.ba.go` clients take `api.Connection`; DF-* get typed calls with compile-checked message names, P05 wraps `*core.Connection` with no glue | trivial (rename) |
| Keys are `"<descriptor name>/<id>"`; descriptor names `<plugin>.<object>` never contain `/` | (a) descriptors declare a `KeyPrefix()` (b) prefix = name by convention | (b) keeps the interface as specified and lets the registry route any key with `Key.Descriptor()` | low |
| `Registry.Register` panics on duplicate/invalid name; `MapRegistry.Add` is the error-returning form | (a) `Register(d) error` (b) panic like `http.Handle`/`gob.Register` | interface in the prompt has no return value; registration is start-up-time programmer territory; tests use `Add` | trivial |
| Interface param names `oldObj, newObj` instead of `old, new` | — | `new` shadows a builtin (revive `redefines-builtin-id`); parameter names are not part of the interface identity | none |
| Mandatory dependency missing in desired ∪ actual fails the transaction before apply; `Optional` only orders | (a) Ligato "pending" objects (b) strict failure | commit is atomic and the API already validates references; pending state hides errors from the operator | low (doc only) |
| Owner stamp = interface tag `"<owner>:<id>"` (`vpp.OwnerTag`, ≤ 63 bytes) | (a) tag = owner only (b) owner + key id (c) owner table only | (b) makes Retrieve self-contained (id recovered from the tag) and survives agent restarts without state | low |
| Fake takes the control-ping reply as an option (`WithControlPingReply`) | (a) hard-code govpp's bundled `memclnt` (b) option | (a) is a different Go type from the project's generated `memclnt`, so generated dump clients would fail their type switch | trivial |
| `File.Secret` added to the specified `File{Mode, Owner, Content}` | — | rule 10 (secrets never logged): `Files.Redacted` and the world-readable check need the flag | none (additive) |
| Allowlist enforced by a test scanning source for binary path literals rather than a runtime registry | (a) central Go map RF-* cannot edit (frozen file) (b) per-package `NewAllowlist` + doc-scan test | (b) lets every RF-* own its list while `ALLOWLIST.md` stays the single human-readable inventory | low |
| `vpptest` helper package added under `internal/vpp/` (owned path, not in the prompt's list) | (a) each DF-*/RF-* re-implements env parsing and the flock (b) shared helper now | the READMEs must answer "how do I test without touching other workers' objects"; a helper is the enforceable answer | trivial |
| `go.fd.io/govpp v0.13.0` added to `go.mod` for the `api.Message`/`api.Connection` types | (a) own `Message` interface mirroring govpp's (b) depend on govpp now | binapi output implements govpp's interfaces; a mirror would need adapters everywhere; govpp is in the stack | low |
