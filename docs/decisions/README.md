# Decisions

- `decision-policy.md` — how agents decide (the 2× rule). Read this first.
- `LOG.md` — every decision taken by agents, one line each. The product owner reviews and may overturn.
- `PENDING-<slug>.md` — decisions waiting for the product owner. Created from `TEMPLATE-PENDING.md`.
- `DEC-<n>-<slug>.md` — resolved PENDING files (renamed, with the answer).
- `os.md`, `vdom.md` — standing decisions.
