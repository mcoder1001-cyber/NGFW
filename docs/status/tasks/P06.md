## Decisions (for the LOG)
| id | decision | options | why |
|---|---|---|---|
| D-P06-1 | Persistence = **Drizzle ORM + node-postgres**, SQL migrations generated by drizzle-kit and committed, applied at boot by drizzle's migrator | (a) Prisma (b) Drizzle (c) raw SQL | no query-engine binary / postinstall (shared pnpm store, `allowBuilds`), TS-first schema, plain SQL migrations reviewable in git |
| D-P06-2 | Candidate = one singleton row, single writer; lock goes stale after `VRX_LOCK_TTL_SEC` (1800) and can be taken over (candidate kept); admin can break a lock (candidate discarded) | (a) per-user candidates (b) singleton + stale takeover (c) no expiry | P06 §2; (c) strands the box when an admin walks away |
| D-P06-3 | Revisions store the **redacted** document; password hashes live only in `app_user` and are hydrated back for validation; a config commit makes `app_user` follow `management.users` (config-sourced users removed, bootstrap admin kept) | (a) hashes in revisions (b) redacted revisions + app_user | D-046/D-070: revisions are shown/exported; one place for credentials |
