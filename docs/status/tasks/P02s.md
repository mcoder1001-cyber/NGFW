## Decisions made (D-016 … D-020, options in the questions file)

- Root keys use `.prefault({})` (fills nested defaults) — every domain schema must accept `{}`.
- Validators: one `semantic/<key>.ts` array per domain, aggregated by `semantic/index.ts`; registry class.
- `x-vrx-ui` via `withUi()` → Zod `.meta()`; Zod 4 copies meta into JSON Schema / OpenAPI.
- `z.looseObject` / `z.strictObject` instead of the deprecated `.passthrough()` / `.strict()`.
- pointer/diff/merge-patch shipped as small working implementations rather than throwing stubs.
