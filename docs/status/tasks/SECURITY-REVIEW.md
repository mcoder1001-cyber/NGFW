No actual production credential or shared host was used in reproduction.

## Inspected attack surfaces

- Authentication and authorization: global APP_GUARD in apps/api/src/app.module.ts, auth/auth.guard.ts and route-guard.test.ts; decorators, JWT/key-ring rotation and key-file descriptor/O_NOFOLLOW checks; password, refresh, API-key scopes, MFA enrollment/challenge fail-closed paths, transport/step-up and lockout. Route default mutations require operator per established P06 role contract, with explicit admin-only secrets/PKI/capture/audit routes. No new privilege model introduced.
- Public routes: pinned health/banner/login/refresh/logout/MFA/OIDC/methods allowlist and HA receive exception. HA receive independently requires encrypted transport, configured peer identity, signature and 30-second timestamp freshness, bounded nonce replay cache and persisted revision monotonicity under commit lock. Cluster SQL uses tagged parameterized expressions. Banner exposes only configured public text. OIDC state/PKCE and one-time MFA challenge are explicit alternate credentials, not unauthenticated configuration writes.
- Raw WebSocket route: telemetry/stream.route.ts authenticates in preValidation before upgrade, avoids URL tokens; relay.service.ts closes expired/revoked credentials. app.ts limits frames to 64 KiB and request bodies to 8 MiB, restricts trustProxy to configured networks; no hop-count trust mode.
- Secrets: secrets.service.ts AES-256-GCM with fresh IV/reference AAD, encrypted version history, metadata-only list; secrets.masterkey and key-file swap tests. secret-delivery.service.ts and agent secretchannel implement private sealed snapshots and bounded validated references/value counts; production desired documents retain references. Renderer rfkit/validator redaction and PKI security cases check errors/read output. Go sealed-cache reads assume private state-directory ownership; no proof of privileged attacker containment beyond that directory boundary is claimed.
- Injection and files: API product code has no runtime child_process bridge to dataplane; renderers/helpers_exec.go permits fixed absolute allowlisted binaries with argv, bounded outputs, deadlines and minimal child environment. Renderer no-shell/allowlist guard and rfkit checks executed. Capture openVPPFile uses O_NOFOLLOW and descriptor ownership/link/inode checks; download/recovery/private 0600 paths and cleanup quotas inspected. Config/rendering identifiers are validated through shared schemas and daemon-specific escaping; scheduler error redaction retained.
- Privileges: deploy/systemd/ngfw-api.service uses unprivileged ngfw, empty capability bound and strict filesystem sandbox; agent root/capability/AF_UNIX socket boundary inspected without widening permissions or changing appliance units. Host runtime and service sandbox effectiveness require deployed acceptance.
- Repository/fixtures: whole-tree gitleaks detect --no-git --redact scan covered approximately 73 MB. Eight generic-api-key findings all contain sanctioned NGFW_TEST_PSK placeholders in rejection/redaction tests: rfkit/fixround_test.go:20, strongswan/apply_test.go:375, rsyslog/rsyslog_test.go:31, scheduler/validator_test.go:371/372, cli/api/transport_test.go:82, schema/domains/vpn.test.ts:197/265. No detector exclusion or CI weakening added. Findings contain no usable credential.
