## Decisions taken (for docs/decisions/LOG.md — options considered)
- **D-P04-1** Rig slot/addressing: `w<N>` prefixes → `10.<N>.{1,2}.0/24`; other prefixes hash into `10.100–199.x.x` (or `VRX_SLOT`). Options: (a) require `--slot` (b) derive from prefix + hash fallback. (b) keeps `rig up <prefix>` one-argument. Reversal: trivial.
- **D-P04-2** Inventory = YAML parsed by python3 + PyYAML (both on the host). Options: (a) flat key=value in bash (b) yq (not installed) (c) python3-yaml. (c) matches the `.yml` requirement with no new install. Reversal: low.
- **D-P04-3** `binapi-gen.sh` uses `--no-source-path-info` (output independent of `VPP_API_DIR`) but keeps the version header (`VPP: 26.06-release`, generator v0.13.0) as provenance, plus a `MANIFEST` of `vl_api_version` CRCs. Options: (a) strip all headers (b) keep both. Reversal: trivial.
- **D-P04-4** `pg-test.sh` stores the generated password only in `/run/vrx-test/<name>/pg.env` (0600, tmpfs) and prints redacted DSNs. Options: (a) fixed well-known dev password in the repo (forbidden by 00-CONTEXT) (b) random per create in /run. Reversal: trivial.
- **D-P04-5** Smoke test is its own Go module (`test/integration/smoke`, replace → apps/agent) rather than a package inside `apps/agent`. Options: (a) inside the agent module (b) own module. (b) keeps `make test` in apps/agent unit-only and lets `tools/ci.sh full` (P09) call `run.sh`. Reversal: low.
- **D-P04-6** `kill-vpp` = `systemctl kill -s SIGKILL vpp` under `flock -x /run/lock/vrx-vpp.lock` + `flock -x` lab lock (after handover only); `restart-vpp` = `systemctl restart vpp` under the same locks. Both wait for `api.sock` + `show version`. Reversal: trivial.
- Not a decision but a fact: PostgreSQL/Valkey were already present → nothing installed (README records versions).
