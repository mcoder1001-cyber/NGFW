     (`packages/schema/dist/json-schema/root.json`) alongside the `DesiredState` descriptor and reports both
     directions: schema leaf without a proto field / proto field without a schema leaf (JSON names), record ↔
     `map<string,…>`, array ↔ `repeated`, object ↔ message, scalar type and integer width (uint32 / uint64 / int32 /
     int64 / double by the schema's range), explicit presence (D-039), secret-flagged leaf with a field (D-040), unions
     of different kinds. Result today: 868 scalar leaves, 191 messages, **0 findings**, 4 accepted differences
     (`acceptedDrift`: the shared `Redistribute` message's own-protocol keys; stale entries fail the test).

     under `CI=1` it fails. `VRX_DRIFT_SCHEMA=<file>` points it at another schema.
   - Document side: `packages/proto/test/parsed-documents.test.ts` — `{}` and every valid example/fixture through
     `RootConfig.parse()` → `redactSecrets` → `DesiredState.fromJSON` → `toJSON` must reproduce the parsed document
