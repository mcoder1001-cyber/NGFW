## What was built (all inside `packages/schema/**` + `docs/contracts/schema.md`)

- **Domains, fully modelled** as `z.strictObject`s with explicit defaults and `withUi()` hints on every field
  (`src/domains/{system,dataplane,interfaces,vrfs,routing,management}.ts`; field tables in `docs/contracts/schema.md`):
  - `system`: hostname (RFC 1123, default `vrx`), timezone (IANA, ICU-checked, default `UTC`), banners, `ntp {enabled, servers[], vrf}`, `dns {servers[], searchDomains[], vrf}`.
  - `dataplane`: workers, corelist[] (core ids), mainCore, rxQueues, txQueues, hugepagesGb, pciWhitelist[].
  - `interfaces`: record keyed by *parent* VPP name → enabled, description, mtu, mac, promiscuous, rxMode, ipv4[]/ipv6[] CIDR, vrf, unnumbered, `subinterfaces` (record by decimal sub-id → vlanId, innerVlanId, dot1ad + the same address fields). Helpers `interfaceNames()`, `subInterfaceName()`.
  - `vrfs`: record name → `{ id: uint32, description? }`; `default` is implicit table 0 (`vrfExists()`).
  - `routing`: `static[]` (prefix, vrf, nextHops[] {address?, interface?, weight}, distance, description), `prefixLists`, `routeMaps` (match/set skeleton), and typed-but-optional `bgp` (peer groups, neighbours, AFs, networks, redistribute), `ospf` (areas, interfaces), `isis`, `rip`, `bfd` (VPP sessions). Single-object consistency via `.refine()` with paths.
  - `management`: `users[]` `{ username, role, scope: '*', passwordHash (writeOnly), sshKeys[], fullName, disabled }`, `aaa { order[], radius, tacacs }` (secretRefs), `tls`, `syslog[]`.
- **Primitives** (`src/primitives.ts`, `src/ip.ts`): 26 primitives incl. the required `ipv4Cidr`, `ipv6Cidr`, `ipAddress`, `macAddress`, `vppInterfaceName`, `hostname`; new `uint32`, `cpuCore`; hostname pattern rewritten without lookaround (RE2-portable); pure prefix arithmetic (`parseCidr`, `isNetworkAddress`, `prefixesOverlap`, …).
- **Semantic validators** (24, named `<domain>.<rule>`, all returning `{ pointer, message }[]` built with `jsonPointer()`):
  `system.vrf-exists`, `system.ntp-server-unique` · `dataplane.workers-match-corelist`, `.corelist-unique`, `.main-core-not-worker`, `.pci-unique` ·
  `interfaces.vrf-exists`, `.address-no-overlap` (both families, per VRF), `.vlan-unique`, `.unnumbered-target-exists`, `.mac-unique` ·
  `vrfs.id-unique`, `.default-is-table-zero` · `routing.vrf-exists`, `.static-nexthop-interface-exists`, `.static-unique`, `.prefix-list-exists`,
  `.route-map-exists`, `.bgp-peer-group-exists`, `.interface-exists`, `.ospf-area-exists` · `management.admin-exists`, `.username-unique`, `.vrf-exists`.
- **Editing/validation helpers**: `validateConfig(doc)` (tier a + b in one call, `pointerIssues()` for problem+json), `mergePatchAt(doc, pointer, patch)` for `PATCH /api/v1/config/{path}` (objects created along the path, array index/append), `mergePatch` unchanged (RFC 7386), `diff` kept with arrays as leaves (D-021; doc updated, TODO removed), `RootConfigInput` type.
- **gen**: unchanged pipeline; every field now emits `title`/`default`/`x-vrx-ui`; record keys emit `propertyNames` patterns; `passwordHash` emits `writeOnly`. Output deterministic (below).
- **Examples**: `minimal.json` (one admin — the smallest committable document), `two-interfaces.json` (all six domains), `invalid-{mtu-out-of-range,unknown-field,unknown-root-key,static-route-family}.json`, `invalid-semantic-{vrf-missing,ipv4-overlap,vlan-duplicate,nexthop-interface,no-admin}.json`; `examples.test.ts` asserts the expected pointer per semantic fixture and idempotent re-parse for valid ones.
- **Tests**: 20 files / 664 tests; primitives get nasty-input tables (control chars, bidi override, zero-width space, Arabic-Indic digits, full-width letters, shell text, 10 k strings, non-strings); `vitest.config.ts` enforces 100 % on primitives, ip, semantic/**, pointer, json, diff, merge-patch, ui, validate.
- **Docs**: `docs/contracts/schema.md` (index + rule + group (a) tables; P02b/P02c link their own files per D-024), `packages/schema/README.md` updated.

## Out of scope / left undone

- WBS D3.3's full BGP surface (AS-path filters, community lists, route reflection, confederation, BGP roles, add-path, VPNv4/v6) —
  only the skeleton required by the prompt is modelled (peer groups, neighbours, AFs with route-map/prefix-list policy,
  networks, redistribute, graceful restart). Per-VRF BGP instances (`router bgp X vrf Y`) are not modelled: one instance with a
  `vrf` field. Both are additive contract changes for the dynamic-routing tasks.
- OSPFv3, MPLS, multicast (D2.x/D3.x beyond the prompt) — not modelled.
- Element-wise diff of keyed arrays — deliberately not done (D-021 kept; `x-vrx-ui.itemKey` hints exist).
- API endpoints, UI, other groups' domains.

## Decisions made (to be copied to `docs/decisions/LOG.md` — options in the questions file)

Strict objects everywhere · `default` VRF implicit (declared only with id 0) · `interfaces.enabled` defaults to `false` ·
`dataplane.corelist` is `number[]` · protocol blocks are optional objects (absent = disabled) · `users[].scope` is the literal `'*'` ·
`management.admin-exists` always enforced (the empty document is valid but not committable; `minimal.json` carries one admin) ·
arrays stay diff leaves for contracts-v1 · `interfaces` keys are parent names, sub-interfaces nested and referenced as `<parent>.<id>` ·
portable (lookaround-free) patterns · `descriptionText` rejects control characters.
