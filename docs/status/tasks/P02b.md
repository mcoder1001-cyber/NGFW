## What was built

- **`domains/nat.ts`** — NAT44 at the top level exactly as docs/04 and `F-nat44-ed-sessions §Contract` expect
  (`mode ed|ei, inside[], outside[], pools[{name, range, vrf?}], staticMappings[{name, local{ip,port?},
  external{ip|pool|interface, port?}, protocol?, vrf?, twiceNat…}], timeouts{udp,tcpEstablished,tcpTransitory,icmp},
  sessionLimit ≥ 1024`), plus `identityMappings`, `loadBalancedMappings`, `outputFeature`, plugin flags, and the
  sibling translators `ipfix, nat64, nat66, nptv6, det44, dslite, map (MAP-E/MAP-T/lw4o6), cnat` (WBS D4.1, D4.3–D4.6).
- **`domains/objects.ts`** — `addresses` (host/network/range/fqdn), `addressGroups`, `services` (tcp/tcp-udp/udp/sctp
  ports + TCP flags, icmp/icmp6 type/code, any, other), `serviceGroups`, `schedules` (recurring HH:MM / once RFC 3339),
  `zones`, `tags` — records keyed by `objectName` (WBS D5.1).
- **`domains/acl.ts`** — `lists` (L3/L4, permit/deny/reflect, object/prefix/inline matches, schedule), `macip`
  (source MAC+mask+prefix), `host` (nftables accept/drop/reject), `attachments` (interface or zone target, direction,
  sequence, **`vrf` first-class**), `macipAttachments`, `hostAttachments` (WBS D5.2, D5.3).
- **Semantic validators** (30 rules, all `{ pointer, message }[]` via `jsonPointer()`): `nat.*` ×14 (interfaces exist,
  inside/outside disjoint, pools ordered + non-overlapping, static-mapping external exactly-one/pool exists/**ports
  require protocol**, identity, load-balanced, ED-only features, VRFs exist, nat64/nptv6/det44/map/cnat/dslite
  consistency), `objects.*` ×8 (names disjoint, tags exist, ranges ordered, group members exist/no duplicates/no
  cycles, service specs, schedules valid, zones reference existing disjoint interfaces), `acl.*` ×8 (sequences unique,
  object/service/schedule references exist, family consistency, tags, MACIP masks, attachments incl. VRF match,
  one MACIP list per interface, host chains). Prototype-safe lookups (`constructor` is a legal name).
- **Tests**: 133 new (domains 49 hostile-input cases incl. `24:00`, `0x50`, `10.0.0.01`, `a'.repeat(64)`, mixed
  families; semantic 53 + 12 example documents). **Examples**: 4 valid documents, 8 schema-invalid, 7 semantic-invalid
  with their expected pointers asserted. **Docs**: `docs/contracts/schema-nat-objects-acl.md` (one table per key,
  one per rule set, examples table, F-nat44 mapping, contract-change rule).
- Fixed two cross-group hazards found by reading the other branches' committed files (read-only `git show`): the
  `export *` collisions `ipv4Address`/`ipv6Address` (P02a) and `l4Port` (P02c) — mine are now private / `l4PortNumber`.
